# План: Адаптивный дизайн для MCP InSales

## Текущее состояние

Приложение — desktop-only SPA. **Нет ни одного `@media` запроса.** Все размеры в `px`. Формы работают на мобильных (`width:100%`), но хедер, таблицы, дашборд и статистика сломаны на маленьких экранах.

## Проблемы (по приоритету)

### P1 — Критичные (не читается на мобильном)
1. **Хедер/навигация** — 5 ссылок + лого + юзер в одну строку, нет бургер-меню → на <768px всё наезжает
2. **Таблицы** — нет `overflow-x:auto` обёртки → на <640px выходят за экран
3. **Дашборд** — `grid-template-columns: 1fr 1fr` захардкожен → на телефоне 2 узких столбца
4. **Статистика админки** — `grid-template-columns: 1fr 1fr 1fr` → на телефоне 3 узких столбца

### P2 — Важные (неудобно)
5. **Padding/body** — `24px` отступы浪费空间 на мобильных
6. **Кнопки действий в таблицах** — не適忟ны для тач-интерфейса

### P3 — Косметические
7. **Inline-стили цветов** в JS-шаблонах → вынести в CSS-классы (не блокер)

## Breakpoints

```
мобильный:  < 640px   (phone)
планшет:    640-1024px (tablet)
десктоп:    > 1024px   (desktop) — текущее поведение
```

## Изменения по файлам

### 1. `web/static/css/style.css` — основные изменения

#### 1.1 Хедер → бургер-меню на мобильных
```css
/* Десктоп (>1024px) — текущее поведение без изменений */

/* Планшет (640-1024px) */
@media (max-width: 1024px) {
  .header { padding: 0 16px; gap: 16px; }
  .header__nav { gap: 2px; }
  .header__nav a { font-size: 13px; padding: 6px 8px; }
}

/* Мобильный (<640px) */
@media (max-width: 640px) {
  .header { flex-wrap: wrap; }
  .header__nav {
    display: none;            /* скрыто по умолчанию */
    flex-direction: column;
    width: 100%;
    order: 3;                 /* под лого и юзером */
    gap: 0;
    background: #fff;
    border-top: 1px solid #eee;
    padding: 8px 0;
  }
  .header__nav.active { display: flex; }  /* JS toggled */
  .header__nav a { padding: 10px 16px; border-bottom: 1px solid #f5f5f5; }
  .header__toggle { display: block; }     /* кнопка-бургер */
}
```

Нужно добавить в HTML:
- Кнопка `.header__toggle` (☰ / ✕) скрыта на десктопе, видна на мобильном
- JS toggle для `.header__nav.active`

#### 1.2 Таблицы → горизонтальный скролл
```css
.table-wrap { overflow-x: auto; -webkit-overflow-scrolling: touch; }
```
Обернуть каждую `<table>` в `<div class="table-wrap">`.

#### 1.3 Сетки → адаптивные
```css
@media (max-width: 640px) {
  .stats-grid { grid-template-columns: 1fr !important; }      /* дашборд */
  .stats-grid--3 { grid-template-columns: 1fr !important; }   /* админ */
}
```

#### 1.4 Body/main padding
```css
@media (max-width: 640px) {
  .main { padding: 12px; }
  .page-header { flex-direction: column; gap: 12px; }
  .page-header .btn { width: 100%; text-align: center; }
}
```

#### 1.5 Карточки форм
```css
@media (max-width: 640px) {
  .card { padding: 16px; }
  .form-group label { font-size: 13px; }
}
```

#### 1.6 Кнопки в таблицах
```css
@media (max-width: 640px) {
  .btn--sm { padding: 8px 12px; font-size: 13px; }  /* увеличить тач-таргет */
}
```

toggleNav() {

```javascript
// В обработчике маршрутизации:
document.querySelectorAll('.header__nav a').forEach(a => {

    document.getElementById('main-nav').classList.remove('active');
  });
});
```

## Проверка

1. `go build ./...` — убедиться что билд проходит
2. `docker compose up -d` — пересобрать и запустить
3. Открыть `https://localhost:8443` в браузере
4. Проверить через DevTools → Toggle Device Toolbar:
   - **iPhone SE (375px)**: бургер-меню, скроллируемые таблицы, 1-колоночные сетки
   - **iPad (768px)**: компактный хедер, таблицы вмещаются, 2-колоночные сетки
   - **Desktop (1440px)**: текущее поведение без изменений
5. `go test ./...` — все тесты проходят
