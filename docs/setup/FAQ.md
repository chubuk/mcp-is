# MCP InSales — Часто задаваемые вопросы

## Установка и запуск

### Как получить ключ InSales?

1. Войдите в панель администратора магазина InSales
2. Перейдите: **Расширения → Разработчикам → Ключи доступа**
3. Нажмите **Создать ключ доступа**
4. Скопируйте **Идентификатор** (ID) и **Пароль**

### Почему Docker контейнер не запускается?

Проверьте:
- Docker установлен: `docker --version`
- Порты свободны: `sudo lsof -i :80` и `sudo lsof -i :443`
- .env файл заполнен: `cat .env`

### Как сменить порты nginx?

В `.env`:
```bash
NGINX_HTTP_PORT=8888
NGINX_HTTPS_PORT=8443
```

Затем: `docker compose up -d`

## AI-клиенты

### Почему AI не видит write-команды?

Включён режим "Только чтение". Проверьте:
- В `.env`: `MCP_READ_ONLY=false`
- Или в Web UI: Магазины → редактировать → снять галку "Только чтение"

### AI получает ошибку 401 "invalid API key"

- Убедитесь что ключ скопирован полностью (64 символа)
- Проверьте что ключ не отозван в разделе AI-ключи
- Убедитесь что заголовок `Authorization: Bearer <ключ>` указан верно

### MCP-клиент не подключается к серверу

Проверьте:
- Сервер запущен: `curl http://localhost:8080/health`
- URL указан верно: `http://localhost:8080/mcp`
- Если клиент в Docker: используйте `http://host.docker.internal:8080/mcp`

## Магазины

### Как добавить второй магазин?

1. Получите второй ключ InSales для нового магазина
2. В Web UI: Магазины → + Добавить
3. Заполните данные нового магазина
4. Сгенерируйте новый AI-ключ для этого магазина

### Как работает "Магазин по умолчанию"?

Если у пользователя несколько магазинов, AI автоматически использует магазин, помеченный как "по умолчанию". Для работы с другим магазином — переключите его как основной.

## HTTPS и сертификаты

### Как настроить HTTPS?

1. В Web UI: Сервер → Включить HTTPS
2. Укажите домен (должен указывать на ваш IP)
3. Укажите email для Let's Encrypt
4. Нажмите "Выпустить сертификат"

### Сертификат истекает — что делать?

Автоматическое обновление настроено по умолчанию. Если не работает:
1. Сервер → Статус сертификата
2. Нажмите "Продлить сертификат"
3. Проверьте логи: `docker compose logs nginx`

### Can't use Let's Encrypt на localhost?

Let's Encrypt не работает с `localhost`. Используйте:
- Самоподписанный сертификат (по умолчанию)
- Реальный домен для production

## Технические вопросы

### Почему super_admin получает запрос на смену пароля?

При первом входе super_admin с дефолтным паролем `password` система требует немедленной смены на безопасный пароль. Это защита от взлома — если кто-то узнает дефолтный пароль, он не сможет им воспользоваться.

**Требования к новому паролю:**
- Минимум 8 символов
- Хотя бы одна заглавная буква
- Хотя бы одна цифра

### Как посмотреть логи?

```bash
# Все сервисы
docker compose logs -f

# Только API
docker compose logs -f app

# Только nginx
docker compose logs -f nginx
```

### Как перезапустить сервис?

```bash
docker compose restart app
```

### Как обновить версию?

```bash
git pull
docker compose build app
docker compose up -d
```

### Как сделать бэкап?

```bash
# Бэкап БД
docker exec mcp_insales_db pg_dump -U admin mcp_insales > backup.sql

# Бэкап .env
cp .env .env.backup
```
