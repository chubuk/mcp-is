# MCP InSales — API Reference

## REST API

### Аутентификация

#### POST /api/register

Регистрация нового пользователя.

**Тело запроса:**
```json
{
  "nickname": "myuser",
  "email": "user@example.com",
  "phone": "+79991234567",
  "first_name": "Иван",
  "last_name": "Петров",
  "password": "securepassword"
}
```

**Обязательные поля:** `nickname`, `password` (минимум 6 символов)

**Ответ (201):**
```json
{
  "user_id": "uuid",
  "nickname": "myuser"
}
```

#### POST /api/login

Вход по email, phone или nickname.

**Тело запроса:**
```json
{
  "login": "myuser",
  "password": "securepassword"
}
```

**Ответ (200):**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user_id": "uuid",
  "nickname": "myuser",
  "role": "super_admin"
}
```

> **Примечание:** Первый зарегистрированный пользователь автоматически получает роль `super_admin`.

#### POST /api/change-password

Смена пароля (требуется JWT).

**Тело запроса:**
```json
{
  "old_password": "старый_пароль",
  "new_password": "новый_пароль"
}
```

**Ответ (200):** `{}`

#### POST /api/forgot-password

Запрос на восстановление пароля.

**Тело запроса:**
```json
{
  "email": "user@example.com"
}
```

**Ответ (200):**
```json
{
  "message": "Письмо отправлено"
}
```

#### POST /api/reset-password

Сброс пароля по токену.

**Тело запроса:**
```json
{
  "token": "токен_из_письма",
  "new_password": "новый_пароль"
}
```

**Ответ (200):** `{}`

#### POST /api/set-email

Установка email (требуется JWT).

**Тело запроса:**
```json
{
  "email": "user@example.com"
}
```

**Ответ (200):** `{}`

### Управление магазинами (требуется JWT)

#### POST /api/shops/test-connection

Проверить валидность ключа InSales.

**Тело запроса:**
```json
{
  "shop_url": "myshop.myinsales.ru",
  "api_key_id": "идентификатор_ключа",
  "api_password": "пароль_ключа"
}
```

**Ответ (200) — успех:**
```json
{
  "ok": true,
  "message": "Соединение успешно установлено",
  "shop": {
    "name": "Мой магазин",
    "domain": "myshop.myinsales.ru",
    "email": "admin@myshop.ru",
    "currency": "RUB"
  }
}
```

**Ответ (200) — ошибка:**
```json
{
  "ok": false,
  "error": "API error 401: Unauthorized"
}
```

#### POST /api/shops

Добавить магазин InSales.

**Тело запроса:**
```json
{
  "name": "Моя Аптека",
  "shop_url": "myshop.myinsales.ru",
  "api_key_id": "идентификатор_ключа",
  "api_password": "пароль_ключа",
  "is_default": true
}
```

**Обязательные поля:** `name`, `shop_url`, `api_key_id`, `api_password`

#### POST /api/shops/:id/check-commands

Проверить и сохранить доступные команды для магазина.

**Ответ (200):**
```json
{
  "commands": [
    {"name": "list_products", "description": "Получить список товаров"},
    {"name": "get_product", "description": "Получить товар по ID"}
  ],
  "count": 30,
  "updated_at": "02.07.2026 14:30"
}
```

**Логика:**
- `is_read_only=true` → 30 read-команд (list_*, get_*, system)
- `is_read_only=false` → все 73 команды
```

      "api_key_id": "key123",
      "is_default": true,

      "created_at": "2026-01-01T00:00:00Z"

```

#### PUT /api/shops/:id

Обновить магазин.

#### DELETE /api/shops/:id

### Админ-панель (требуется JWT + роль admin/super_admin)

#### GET /api/admin/users

Список пользователей с пагинацией и поиском.

**Параметры запроса:**
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| page | integer | 1 | Номер страницы |
| per_page | integer | 20 | Записей на странице (макс. 100) |
| q | string | — | Поиск по никнейму, email, телефону, ФИО |

**Ответ (200):**
```json
{
  "items": [
    {
      "id": "uuid",
      "nickname": "admin",
      "email": "admin@test.com",
      "phone": "+79991234567",
      "first_name": "Иван",
      "last_name": "Петров",
      "role": "super_admin",
      "is_active": true,
      "created_at": "2026-01-01T00:00:00Z"
    }
  ],
  "total": 42,
  "page": 1,
  "per_page": 20
}
```

#### GET /api/admin/users/:id

Получить пользователя по ID.

**Ответ (200):** объект пользователя (см. выше).

#### PUT /api/admin/users/:id/role

Изменить роль пользователя (требуется `super_admin`).

**Тело запроса:**
```json
{
  "role": "admin"
}
```

**Допустимые роли:** `user`, `admin`, `super_admin`

**Ограничения:**
- Нельзя изменить роль `super_admin` (если вы не он сам)
- Только `super_admin` может менять роли

**Ответ (200):**
```json
{
  "id": "uuid",
  "role": "admin"
}
```

#### PUT /api/admin/users/:id/status

Заблокировать/разблокировать пользователя.

**Тело запроса:**
```json
{
  "is_active": false
}
```

**Ограничения:**
- Нельзя заблокировать `super_admin`
- Нельзя заблокировать себя

**Ответ (200):**
```json
{
  "id": "uuid",
  "is_active": false
}
```

#### DELETE /api/admin/users/:id

Удалить пользователя.

**Ограничения:**
- Нельзя удалить `super_admin`
- Нельзя удалить себя

**Ответ (200):**
```json
{
  "id": "uuid"
}
```

#### GET /api/admin/stats

Статистика системы.

**Ответ (200):**
```json
{
  "total_users": 5,
  "total_shops": 3,
  "total_ai_keys": 8
}
```

### Настройки сервера (требуется JWT + admin/super_admin)

#### GET /api/admin/server

Получить текущие настройки сервера и статус сертификата.

**Доступ:** admin, super_admin

**Ответ (200):**
```json
{
  "domain": "example.com",
  "https_enabled": true,
  "auto_renew": true,
  "renew_days_before": 30,
  "cert_expires_at": "2026-12-01T00:00:00Z",
  "cert_issuer": "Let's Encrypt",
  "cert_needs_attention": false,
  "last_renew_error": "",
  "retry_count": 0,
  "last_retry_at": "",
  "letsencrypt_email": "admin@example.com"
}
```

#### PUT /api/admin/server

Обновить настройки сервера.

**Доступ:** super_admin only

**Тело запроса:**
```json
{
  "domain": "example.com",
  "https_enabled": true,
  "auto_renew": true,
  "renew_days_before": 30,
  "letsencrypt_email": "admin@example.com"
}
```

**Ограничения:**
- `renew_days_before`: минимум 14, максимум 60

#### POST /api/admin/server/cert-issue

Запросить выпуск сертификата Let's Encrypt.

**Доступ:** admin, super_admin

**Требования:**
- Домен не должен быть `localhost`
- Email для Let's Encrypt должен быть установлен

**Ответ (200):**
```json
{
  "message": "certificate issuance started",
  "domain": "example.com"
}
```

#### POST /api/admin/server/cert-renew

Продлить сертификат Let's Encrypt.

**Доступ:** admin, super_admin

**Ответ (200):**
```json
{
  "message": "certificate renewal started",
  "domain": "example.com"
}
```

## MCP (Model Context Protocol)

### Транспорт

- **HTTP**: `POST http://localhost:8080/mcp`
- **SSE**: `GET http://localhost:8080/mcp`

### Протокол

JSON-RPC 2.0

### Авторизация

Все MCP-запросы требуют заголовок:
```
Authorization: Bearer <AI_KEY>
```

### Методы

### initialize

Инициализация MCP-сессии.

```json
{
  "jsonrpc": "2.0",
  "method": "initialize",
  "id": 1
}
```

Ответ:
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "protocolVersion": "2024-11-05",
    "capabilities": {"tools": {}},
    "serverInfo": {
      "name": "mcp-insales",
      "version": "0.1.0"
    }
  }
}
```

### tools/list

Получить список доступных инструментов.

```json
{
  "jsonrpc": "2.0",
  "method": "tools/list",
  "id": 2
}
```

### tools/call

Вызов инструмента.

```json
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "id": 3,
  "params": {
    "name": "имя_инструмента",
    "arguments": {"параметр": "значение"}
  }
}
```
